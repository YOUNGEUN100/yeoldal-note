# 열 달 노트

서울 임산부를 위한 주차별 검사·지원 체크리스트예요. 출산예정일을 넣으면 오늘 기준 임신 주차를 계산하고, 지금 챙길 일과 놓친 일을 먼저 보여 줘요.

## 기능

- **주차 그림**: 엄마의 배와 아기(배아→태아)가 주차에 따라 바뀌어요. 슬라이더로 4~40주를 미리 볼 수 있어요.
- **지금 챙길 일**: 지난 주차에 아직 체크하지 않은 일과 앞으로 3주 안에 할 일을 모아 보여 줘요.
- **주차별 체크리스트**: 임신 초기·중기·후기·출산 후로 나뉘어 있어요.
- **분류 필터**: 병원·보건 / 정부 신청 / 직장 / 생활 팁 중 하나만 골라 볼 수 있어요.
- **서울시·우리 구 혜택**: 사는 구를 고르면 서울시 공통 혜택과 구 자체 사업을 보여 줘요.
- **저장**: 체크 내용과 예정일, 고른 구는 각자 브라우저에 저장돼요. 서버로 보내지 않아요.
- **기록 옮기기**: 백업 코드(`YD1.`로 시작)를 복사해 다른 기기에 붙여 넣으면 기록이 옮겨져요. 코드도 어디에도 저장되지 않아요.

- **앱으로 설치**: 크롬·엣지에서는 "앱으로 설치" 버튼이나 주소창의 설치 아이콘으로, 아이폰 사파리에서는 공유 → "홈 화면에 추가"로 설치해요. 설치하면 인터넷이 없어도 마지막으로 본 내용을 열 수 있어요.

## 출처 원칙

- 정부·공공기관 공식 홈페이지를 기준으로 해요 (정부24, 정책브리핑, 복지로, 국민건강보험공단, 고용노동부, 찾기쉬운 생활법령, 질병관리청, 서울시, 구청·보건소 등).
- 항목마다 출처 링크를 붙였어요. 정부 기준이 없는 항목은 "정부 기준 없음 · 생활 팁"으로 표시해요.
- 공식 자료끼리 내용이 다르면 둘 다 적고 "주소지 보건소에 확인"을 붙여요.
- 의학 내용은 일반 기준이에요. 검사 시기와 복약은 담당 의료진과 상의하세요.

## 업데이트

매달 1일에 공식 홈페이지를 다시 확인해 바뀐 혜택을 반영해요. 페이지 맨 아래 "마지막 점검" 날짜로 확인할 수 있어요.

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | 웹페이지 전체 (HTML·CSS·JS 한 파일) |
| `manifest.webmanifest` | 앱 이름·아이콘·색 (설치용) |
| `sw.js` | 서비스 워커: 최신 내용을 먼저 받고, 인터넷이 끊기면 저장본을 보여 줘요 |
| `icons/` | 앱 아이콘 (192·512px, 마스커블, 애플 터치 아이콘, 파비콘) |
| `design/tokens.json` | 디자인 가이드의 색·글꼴·간격·모서리 값 |

체크리스트 내용은 `index.html` 스크립트 안의 `ITEMS`(주차별 할 일), `SEOUL`(서울시 공통 혜택), `GU`(구별 사업)에 들어 있어요.

## 로컬에서 보기

`index.html`을 브라우저로 열면 돼요. 별도 설치나 빌드는 필요 없어요. 앱 설치와 오프라인 기능은 https 주소(GitHub Pages, Netlify 등)에서만 동작해요.
